## ✨ 주요 기능
1. **실시간 스마트 생성**:
   - 100+개의 엄선된 인도 성인 이름(남/여)과 대표 성씨, 공식 은행/결제 앱 핸들(@paytm, @ybl, @oksbi, @sbi 등) 조합.
   - 댓글에서 가장 성공률이 높은 `이름 + 12 / 123 / 1234 + @핸들` 우선 생성 모드 제공.
2. **실시간 성공 / 실패 피드백 시스템**:
   - **실패(👎) 등록**: 결제 시스템에서 에러/중복이 뜬 ID를 실패 목록에 기록하고, **이후 자동 생성 대상에서 영구 제외**.
   - **성공(👍) 기록**: 성공한 유효 ID를 누적 저장하여 바로 복사하거나 텍스트로 내보낼 수 있음.
3. **로컬 스토리지 영구 저장**: 브라우저를 닫거나 새로고침해도 성공/실패 목록이 그대로 보존됩니다.
4. **일괄 생성 (5개 / 10개)**: 여러 개를 한 번에 생성하여 편리하게 테스트 가능.

## 🔒 보안 및 결제 안전성 안내 (Apple Support #108110 & RBI)
* 가상 UPI ID는 은행 핀(PIN) 및 OTP 인증이 불가능하므로 **추가 결제 승인이 100% 불가능**합니다.
* 충전해둔 인도 기프트카드(Apple ID / Google Play 잔액)에서만 결제되며, 결제창 무한반복 락을 해제하기 위한 더미 결제수단으로 안전하게 활용됩니다.
