## 0.4.0 로컬 실험실

실제 로컬 HTTP 서버(127.0.0.1:18741)와 실제 로드한 확장을 연결해 점검/실행/오류 재시도/두 Cancel/모의 성공/로그 내보내기/중지/초기화를 시험합니다. 이 테스트는 Apple URL 응답 대체 방식과 별도로 수행합니다. 페이지의 외부 웹 요청이 없고, JSON에 simulation 표시가 들어가는지 확인합니다. 샘플의 클릭 횟수는 페이지 하단에서 사용자가 직접 비교할 수 있습니다.

## 이번 수정의 근거

사용자 캡처에는 활성 구독 카드, 분리된 YouTube/Premium 제목과 `Renews 1 November`가 표시됐습니다. 0.1.0은 이어진 상품명과 `Renews on`만 인식하고, 활성 점검 결과도 따로 설명하지 않았습니다. 재현 테스트에서 7개 실패를 확인한 뒤 수정했습니다. 활성 여부는 관찰 결과로 표시하며, 이 도구가 결제를 성공시켰다고 표시하지 않습니다.

별도 코드 리뷰에서 중첩된 제목을 두 구독으로 세는 문제를 추가 재현해 수정했습니다. 명시적 카드 경계와 제목 중복 제거를 사용하며, 다른 구독의 갱신일을 빌려오는 회귀도 확인했습니다.

- 380px 폭 실행 화면이 600px 높이 안에 들어오는지 확인. 큰 소개 문구 제거.
- 실행/로그/설정 탭, 키보드 전환, 전체 현재 이력(최대 200개), JSON 내려받기.
- 영어 선택 → 로컬 저장 → 팝업 재오픈 → 영어 유지 검증.
- 모의 갱신 실행의 실제 로그가 영어로 표시되고, 한국어로 되돌리면 같은 이력도 한국어로 바뀌는지 검증.
- 스크린샷: ready-preview.png, active-preview.png, english-preview.png, logs-preview.png. 개발 폴더에만 포함.

## 검증 한계

사용자 스크린샷의 보이는 구조를 테스트 HTML로 재현했습니다. 스크린샷만으로 실제 DOM 전체를 확인한 것은 아닙니다. 통합 테스트의 Apple URL은 모두 모의 응답으로 대체했으며, 실제 계정 로그인·결제·구독 변경은 하지 않았습니다. 실제 서비스 호환성, Edge 설치, 장시간 절전/백그라운드, 공개 배포는 미검증입니다.

## 배포 파일

`package.ps1`은 manifest의 버전으로 `wagal-macro-0.4.0.zip`을 만들고, 포함된 런타임·문서·실험실 18개 각각의 SHA-256을 원본과 대조합니다. 구버전 ZIP은 보존합니다. 타사 코드, 브라우저 프로필, 테스트 의존성은 포함하지 않습니다.

## 0.4.0 재시도 설정 및 복구

0 = 횟수 무제한, 시간 제한 유지. 기본 간격 30±5초, 설정에서 랜덤 범위 0–60초 조절. 엔진 경계값/시간 제한 시험과 실제 확장 무제한 실행·랜덤 범위·∞ 표시 시험 통과. 중지/확인 필요 상태에서 수동 새로고침 가능하며 자동 재개하지 않음을 설치형 시험으로 확인. 자동 새로고침은 결제 결과를 놓칠 수 있어 추가하지 않음. 랜덤 간격이 Apple 오류를 방지한다는 효과는 검증하지 않음.
