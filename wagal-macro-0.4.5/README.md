# 와갈매크로 0.4.5

최종 0.4 계열의 UI·가이드·차단 안내·후기·설정을 유지한 프레임 전환 수정본입니다. Renew와 Confirm이 서로 다른 프레임에 있어도 단계별로 탐색합니다. 유일한 확인창의 상품과 금액이 일치할 때만 클릭합니다.

## 업데이트
1. 다른 갱신 매크로와 이전 와갈매크로를 모두 끕니다.
2. 0.4.5 ZIP을 풀고 chrome://extensions에서 개발자 모드 → 압축해제된 확장 프로그램 로드 → manifest.json이 있는 폴더를 선택합니다.
3. 같은 기존 설치 폴더에 덮어쓴 경우 확장 관리 화면의 새로고침을 누릅니다.
4. Apple 탭도 새로고침합니다. 팝업 버전 0.4.5를 확인하고 화면 점검 후 실행하세요.

## 동작
- 최대 횟수 기본 50회, 기준 간격 기본 3초. 0은 횟수 무제한이며 기존 시간 제한 없는 설정을 유지합니다.
- 랜덤 간격 체크박스, 한국어/English, 로그 JSON 내려받기를 유지합니다.
- Confirm 화면에서 직접 시작 가능. 실행 중지 및 중지/확인 필요 상태의 수동 새로고침 지원.
- 단계별 대기는 최대 30초. 자동 새로고침/자동 재시작은 하지 않습니다.
- 버튼을 누른 뒤 중지해도 이미 보낸 요청은 취소되지 않습니다.

## 문제 확인
로그 탭 → 내려받기의 JSON에는 버전, 실행 단계, 판정 종류 및 프레임 번호가 기록됩니다. 계정 비밀번호나 쿠키를 요구하지 않습니다.

## 로컬 시험
Node.js 설치 후 start-test.cmd를 실행하면 http://127.0.0.1:18741/wagal-test/ 에서 모의 화면을 사용할 수 있습니다. 실제 Apple 계정이나 결제에 요청하지 않습니다.

38개 개발 검증이 통과했습니다. 다른 출처의 Renew/Confirm/오류 iframe을 연결한 설치형 시험을 포함합니다. 실제 Apple 결제 성공을 확인한 것은 아닙니다. 상세 결과는 VALIDATION.md에 있습니다.
